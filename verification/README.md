На всех этих строках вероятности точно совпали с исходным компонентом; новый ансамбль сохранен, загружен и проверен на полном test. Платформа: Python 3.12.10, macOS-26.6.2-arm64-arm-64bit, 8 ядер, 16 GiB RAM, два потока обучения, без GPU. Другие платформы отдельно не проверены. Новая независимая оценка F1 и приватный результат неизвестны.
