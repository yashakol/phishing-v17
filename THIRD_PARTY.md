# Источники данных

Метки обучения, URL и статический HTML получены от организатора соревнования. Публичный SQL и опубликованные метки test в V17 не используются. Производные кеши test не содержат меток.

Данные организатора и готовые веса входят в этот репозиторий для передачи жюри. Условия использования исходных данных определяются правилами организатора.

Версии сторонних библиотек закреплены в `requirements.txt`; условия их лицензий сохраняются. Лицензию авторского кода участник определяет отдельно.
