# V17: комплект для воспроизведения решения

Этот репозиторий содержит исходники, обученный ансамбль, входные данные, матрицу финального обучения и ожидаемый файл `submission_content_v17.csv`. После клонирования отдельные архивы с моделями или данные из папки автора не нужны. Большие файлы хранятся в `payload/` частями и автоматически восстанавливаются с проверкой SHA256.

Public F1=0.995082 сообщен участником и записан в [evidence/tournament_feedback.json](evidence/tournament_feedback.json). Приватная оценка неизвестна. Техническое воспроизведение проверяет совпадение конкретного файла, а не заново измеряет F1 на скрытых метках.

## Запуск для жюри

Нужен Python 3.12. Проверенный вариант: Python 3.12.10, macOS 26.6.2 arm64, 8 ядер, 16 GiB RAM. Это фактический проверенный стенд; минимальные требования к памяти отдельно не измерены. GPU не используется. Все 37 версий библиотек закреплены в `requirements.txt`.

Из корня репозитория:

```sh
python3.12 reproduce.py setup
python3.12 reproduce.py verify
python3.12 reproduce.py
```

Первая команда создает собственное `.venv` и устанавливает зависимости. Для нее нужен доступ к PyPI либо совместимые wheels, переданные через `--wheelhouse PATH`. На macOS установщик при необходимости исправляет связь OpenMP только внутри нового окружения; системные библиотеки не изменяются. На других ОС этот специальный шаг не применяется. Другие ОС и архитектуры в этой поставке отдельно не проверены.

Команды `verify`, `predict` и `train` не обращаются к фишинговым сайтам. Во время вычисления модели сеть заблокирована. Если `.venv` еще отсутствует, запуск без указания действия сначала выполняет установку.

Результат: `outputs/submission_content_v17.csv`. В файле 16000 строк и 6016 положительных ответов. Ожидаемый SHA256:

```text
806287876e1ca07abf2696189e6de290252e1ff907dfdb78156c271e1a292458
```

Несовпадение контрольной суммы или порядка строк завершает команду ошибкой. Эталон `expected/submission_content_v17.csv` применяется только для проверки готового результата.

## Обучение и тесты

```sh
python3.12 reproduce.py train
python3.12 reproduce.py test
```

`train` повторяет финальный этап V17: обучает CatBoost-специалиста на зафиксированных 7119 собственных строках, сохраняет новый ансамбль `outputs/retrained_v17.joblib` и получает `outputs/retrained_submission_v17.csv`. Обученные базовые компоненты и матрица признаков являются явно включенными зафиксированными входами этого этапа. Роль этих входов и границы повторного обучения раскрыты в [docs/REPRODUCIBILITY.md](docs/REPRODUCIBILITY.md).

Модель повторного обучения не перезаписывается. Для еще одного прогона обучения используйте новую чистую копию репозитория. Файлы в `payload/` при вычислениях не изменяются.

В этой поставке 132 теста: исторические тесты модели и новые проверки восстановления данных, поврежденных частей, путей и порядка CSV. Отчеты фактических прогонов находятся в `verification/`.
