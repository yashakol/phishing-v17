# Передача решения организатору

Основание - текст ТЗ, присланный участником: воспроизводимое решение, исходный код модели, сведения об окружении, CSV `Id,Predicted` в порядке test и соблюдение прав на сторонние данные. Шаблон отдельного репозитория организатором не задан.

| Требование | Что предоставлено |
| --- | --- |
| Исходный код модели | `phishing_url/`, совместимые классы `experiments/`, исторические `scripts/` и активный `run_solution.py` |
| Данные и готовые веса для воспроизведения | Полный необходимый состав в `payload/`, контрольные суммы в `payload/manifest.json` |
| Техническая информация об окружении | Python 3.12.10, `requirements.txt`, `verification/environment_setup.json`, инструкции в README |
| Повторное получение ответов | `python3.12 reproduce.py`; проверка всех 16000 строк и SHA256 исходной отправки |
| Повторное обучение | `python3.12 reproduce.py train`; точный объем обучения описан в `docs/REPRODUCIBILITY.md` |
| Происхождение результата | Сохраненные протоколы `evidence/` и новые журналы `verification/` |
| Формат CSV | Заголовок `Id,Predicted`, Id от 0 до 15999, только классы 0/1; порядок проверяется |

По присланным правилам участник выбирает два решения, а победители определяются приватной таблицей. Если участник попадает в требуемые правилами места, он сам передает код и сведения организатору в установленный срок трех суток. Этот репозиторий ничего не отправляет на турнир и не подтверждает приватную оценку.

Данные организатора входят в поставку. Исходники и необходимые входы находятся в [репозитории решения](https://github.com/yashakol/phishing-v17). Для получения копии:

```sh
git clone https://github.com/yashakol/phishing-v17.git
cd phishing-v17
python3.12 reproduce.py verify
```

В комплект обязательно входят `payload/`, `expected/`, исходники, требования и описания. `.venv/`, `.runtime/` и `outputs/` создаются заново. Отдельные части `payload/parts/` не следует удалять или объединять вручную.

При передаче приложите ссылку на репозиторий и идентификатор коммита, имя отправленного CSV и его SHA256 из `delivery_config.json`. Правила не требуют публиковать данные для всех пользователей Git.
